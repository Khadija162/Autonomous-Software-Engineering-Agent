# Open evaluation data

The checked-in `sample_repo/` example and tests are original MIT-licensed educational data. They offer a safe, reproducible starting point for issue investigation.

For realistic open-source evaluation, see https://www.swebench.com/ and the public SWE-bench datasets. Respect each upstream source repository's licensing and usage terms. Do not commit full third-party repository snapshots to this project.

SWE-bench execution may run untrusted code: use dedicated disposable isolated compute, not the API container or a production host.
